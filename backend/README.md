# Kandy Ads Backend

New Node.js backend/API for the Kandy Ads operations platform.

Target responsibilities are defined in `/TASKS.md`: authentication/authorization, CRM, enquiries, quotations, projects, jobs/tasks, employees/time tracking, vendors/outsourcing, materials/inventory, purchasing, expenses, installations, invoices/payments, profitability, documents, notifications and audit logging.

Planned stack: Node.js + TypeScript + Fastify + Prisma + MySQL + Zod.
