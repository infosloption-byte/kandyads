# Industry illustrations

The Industries page uses six **AI-generated conceptual illustrations** prepared for KandyAds' website, not photographs of completed customer projects. Do not describe them as real client case studies.

The optimized `frontend/src/assets/industries/industry-scenes.webp` is a 3-column by 2-row image atlas to avoid six separate file requests. Each tile is 16:9. The gallery displays the correct tile via CSS background size and background position.

| Tile | Industry / illustrated environment |
| --- | --- |
| Column 1, row 1 | Retail & Supermarkets — branded shopfront |
| Column 2, row 1 | Hotels & Tourism — resort entrance |
| Column 3, row 1 | Food & Beverage — café storefront |
| Column 1, row 2 | Corporate / Banking & Finance — office reception and wayfinding |
| Column 2, row 2 | Healthcare — hospital and pharmacy |
| Column 3, row 2 | Education — university campus signage |

Real Estate intentionally reuses the retail/commercial-property visual, and Banking & Finance uses the corporate entrance/wayfinding visual. No KandyAds portfolio images were altered.
